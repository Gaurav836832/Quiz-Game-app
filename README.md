# Quiz Game App

A simple and interactive **Quiz Game App** built using **HTML, CSS, and JavaScript**. The application displays multiple-choice questions, allows users to select answers, keeps track of their score, and shows the final result.

## Features

* Multiple-choice quiz questions
* Randomized answer options
* Interactive answer buttons
* Automatic score calculation
* Displays the final score
* Next-question functionality
* Simple and responsive user interface
* Instant feedback after selecting an answer

## Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and layout
* **JavaScript** – Quiz logic and DOM manipulation

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Gaurav836832/Quiz-Game-app.git
```

2. Open the project folder:

```bash
cd Quiz-Game-app
```

3. Open the `index.html` file in your browser.

You can also use the **Live Server** extension in VS Code to run the application.

## How to Play

1. Start the quiz.
2. Read the displayed question.
3. Select one of the available options.
4. Your score will be updated automatically.
5. Continue until all questions are completed.
6. View your final score at the end of the quiz.
